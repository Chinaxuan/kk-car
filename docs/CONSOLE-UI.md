# 统一控制台

所有功能仍运行在树莓派 OpenWrt 上，沿用原 LuCI 管理员会话。此次整合的是界面结构与操作形式，未增加浏览器常驻要求。

## 页面与导航

| 页面 | 内容 |
| --- | --- |
| 行车总览 | 四段连接路径、八项重点数据、网络历史、五组详细指标、终端与网络检查 |
| 连接设置 | VPN、网口、热点和线路维护，保留修改后的两分钟确认回退 |
| 网络守护 | 多目标探测、故障与恢复记录、检测和恢复策略 |
| 蜂窝与通信 | 总览、网络详情、短信、电话、流量、定位、设备；页内功能栏切换 |
| 电源与设备 | UPS 状态、充放电曲线、输入/电池/控制器诊断、常用与高级控制 |
| 通知中心 | 总开关、17 类事件、6 项阈值、3 个机器人地址与发送结果 |
| 设置中心 | 电子纸、HDMI、自动检查、11 项后台服务与模块入口 |

电脑使用统一左侧导航，页头固定为标题、用途说明、更新时间与主要操作。手机点「功能」展开七个入口；页内功能与表单自然换行，不要求横向滚动整个页面。原 OpenWrt 高级管理和退出入口位于全局导航底部。

首页保持数据密度和重点数字层级；窗口高度较小时可滚动查看全部详细指标。状态颜色带文字，电量与电流估算仍明确标注未校准。网站地区结果、隧道连接和实际业务可用性保持区别。

## 实现边界

- 共用 `console.js` 创建导航、标题、更新时间、手机菜单与唯一主工作区；`console.css` 定义统一颜色、字重、间距、表单、按钮、焦点和反馈样式。
- 原控件节点移入共用框架，保留唯一 ID、输入值、监听器、RPC 参数、轮询和确认流程；不克隆短信/电话/电源控件，不增加状态采集任务。
- 全局导航共用一份定义。DJI 原内部侧栏改为页内功能栏，保留 URL 的功能锚点。电话音频及麦克风使用原有 HTTPS 路径。
- 不改变当前 VPN、热点、WAN、硬件寄存器、电池参数或屏幕设置。刷新前请先处理页面中尚未保存的输入。

## 部署与回退

仅更新八个前端资源：六个页面脚本与 `console.js` / `console.css`。更新前私下备份被替换文件；版本化样式加载后重新打开页面。把两个共用资源加入现有 sysupgrade 保留列表，无需重启网络、DHCP、VPN、UPS 或管理 RPC。

回退时成组恢复六个页面脚本及其对应资源版本；旧页面不依赖共用框架。不要同时保留新版页面和缺失的 `console.js`。原业务配置与历史日志不参与界面回退。

## 验证

实机 Chrome 在桌面和 390×844 手机尺寸下回读七个页面；全局入口一致，只有一个主工作区，未发现重复控件 ID 或页面横向溢出。DJI 七个子功能分别回读；两张电池曲线、通知事件/阈值/地址、设置字段与服务入口仍在。只做导航、输入和读取，不发送短信、拨号、推送或执行电源操作来验证外观。

部署前后网络、无线、DHCP、防火墙配置校验值及系统启动标识一致；经 VPN 探测 4 次全部响应。该验证不替代移动通话、完整充放电或故障恢复的实物验收。
