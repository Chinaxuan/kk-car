# DJI 4G 模块控制页

连接 KK-Car 后，用原 OpenWrt 管理员账号打开 `http://192.168.88.1/cgi-bin/luci/admin/kkcar_dji`。这是独立于网络总览的模块页面；手机也可使用。当前适配对象是已转为 QMI 网络接口的 DJI 一代模块（Baiwang / QDC507），不是所有 DJI 蜂窝产品。

## 已接入的能力

| 页面功能 | 数据或操作来源 | 使用边界 |
| --- | --- | --- |
| SIM、注册、运营商和数据会话 | QMI 状态缓存 | 注册、取得 IP 与实际访问分别判定 |
| RSRP、RSRQ、SINR、RSSI 与收发流量 | QMI 与实际 `wwan` 网卡 | 信号约 30 秒更新；接口字节数不是运营商账单 |
| 频段、固件、模块温度 | 模块 AT 只读查询 | 频段只展示白名单字段；温度为 `AT+QTEMP` 第一值，即基带芯片温度 |
| SIM 锁状态与邻区信号 | `AT+CPIN?` 和 `AT+QENG="neighbourcell"` | 邻区只汇总同频/异频数量与最强 RSRP，不保存 Cell ID、PCI、TAC 或原始应答；不提供输入 PIN/PUK |
| 刷新状态 | 重新采集 QMI、AT 与短信仓占用 | 不重启网络、Wi-Fi 或 VPN |
| 重连 DJI 数据网络 | 仅重启 QMI `wan` 逻辑接口 | 使用蜂窝时会短暂中断上网与 VPN；不改 LAN、热点、路由配置 |
| 短信仓占用 | `AT+CPMS?` | 不读取正文；模块当前曾出现 23/23 已满，新短信可能无法接收 |
| 读取短信列表和单条正文 | 用户点击后查询 | 读取列表可能把未读短信标为已读；正文仅在点选单条后进入当前页面 |
| 发送和删除单条短信 | 用户填写并确认后执行 | 发送可能产生费用；删除不可恢复；没有自动发送或自动清理 |

短信目录、号码和正文不会写入公开仓库、长期历史、飞书推送或浏览器本地存储。发送请求只在设备 `/tmp` 的私有目录中短暂存在，完成后删除；串口回复也只暂存在私有内存文件。页面仍需使用可信内网和管理员账号。

## 尚未开放的功能

模块响应 GNSS 状态命令，但实际天线和定位尚未验收。当前保持 GNSS 关闭，页面仅显示状态，不开放启动按钮或记录轨迹。只有可靠备用上网链路、定位天线和停车测试条件齐备后，才能验证首次定位、持续速度与断电恢复。eSIM 查询指令在这只模块上返回错误；页面不提供 eSIM 设置。也未做频段锁定、运营商强制切换或固件刷写，这些操作可能显著降低移动中的联网成功率。

短信发送与删除在上线前只通过模拟串口测试；实际短信收发需要用户在页面明确选择号码和内容后才能验收。模块存储满时，可在页面逐条确认删除，但先检查是否有需要保留的验证码或其他重要短信。暂不提供自动清空。

## 故障判断

页面显示“模块未连通”时，先到网络总览确认 USB 识别、SIM、QMI 数据会话和当前出口。短信操作显示“忙碌”时，等待 AT 状态采样或上一项短信操作结束再试。短信“发送结果未确认”不能直接视为失败，避免立即重复发送。定位栏显示“未验收”不代表模块保证有可用 GNSS 天线。

接入过程和 QMI 回退见 [DJI 4G / QMI 接入](DJI-QMI.md)，整体部署顺序见 [部署与更新](DEPLOYMENT.md)。
