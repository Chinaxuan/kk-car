# 使用说明

## 登录与首页

连接 KK-Car 热点或 LAN 后，打开 `http://192.168.88.1/cgi-bin/luci/admin/kkcar`，使用已有 OpenWrt 管理员登录。顶部「高级管理」可进入原 LuCI；简易页不会取代原系统配置入口。

首页统一展示出口、VPN、热点、两张历史图、32 项系统和网络指标、设备列表以及常用设置。电脑宽屏采用单屏布局，手机自然纵向排列，没有内容分页或设置选项卡。

- **VPN 已连接**：表示隧道已建立，实际业务还应通过网络检查确认。
- **注意供电**：来自树莓派内核的欠压或降频标志，不是输入电压测量。先检查电源与线缆。
- **流量**：速率单位 Mbps，累计单位 B / KB / MB / GB；均为接口计数。
- **CPU / 负载**：CPU 是全部核心平均忙碌比例，1/5/15 分钟负载不是百分比。
- **本 SA 收 / 发**：IPsec 安全关联的流量，换钥后可能归零。

## VPN 操作

- 「暂停 VPN」：确认后停止 VPN；国内直连保留，公司内网和国外业务暂停。
- 「启动 VPN」：恢复连接，等待隧道建立后点击网络检查。
- 「重新连接 VPN」：用于手动排障，会短暂影响经 VPN 的连接。
- 「开机自动连接 VPN」：勾选后保存，仅决定下次开机是否启动。

原 WireGuard 已停止，配置留在设备上。不要同时启动两套 VPN；若要恢复 WireGuard，需要同步调整路由和分流。

## 热点名称、密码与频段

1. 修改热点名称；密码留空表示保留当前密码，新密码为 8–63 位。
2. 选择 5 GHz 或 2.4 GHz，带宽均为 20 MHz。
3. 勾选确认提示并保存。
4. 重新连接新热点，在页面倒计时结束前确认保留。

确认窗口为 125 秒，包含应用前约 4 秒等待。超时或试用中重启会恢复旧配置。树莓派内置无线当前只运行一个 AP / 一个频段，不会同时提供两种频段。

## 网口 LAN / WAN

**LAN**：网口和热点处于同一内网，适合接电脑等设备。

**WAN**：网口通过 DHCP 从上级获取地址，有线探测连续通过后优先于 4G；有线故障后回到 4G。请通过 Wi-Fi 操作并按倒计时确认，否则自动回退。

有线网段与车内 LAN 或上网棒网段冲突时，不选择有线。切换出口可能重建 VPN，现有下载或通话可能需要重连；不是无缝会话迁移。

## 六项网络检查

树莓派每 10 分钟自动执行六项网络检查，无需保持 Mac 或浏览器在线；开机自动启动。也可点击「检查网络」立即检测，通常约 15 秒内完成，页面保留检查时间。后台会定期访问下表中的目标，包括两个 AI 网站。

自动检查与手动检查共用任务锁，遇到其他管理操作会延后重试，不会重叠执行；检查失败只更新结果，不重启网络或 VPN，也不改变现有飞书推送设置。停用或恢复方法见[部署说明](DEPLOYMENT.md#每-10-分钟自动网络检查)。

| 检查项 | 含义 |
| --- | --- |
| 国内出口 | 从当前选中的物理 WAN 请求国内 IP 查询目标 |
| VPN 出口 | 经 VPN 请求 Cloudflare，显示出口 IP 与地区 |
| 公司服务 | 经 VPN 请求指定内网 HTTP 服务 |
| 国外域名解析 | 检查本机 DNS 是否能解析国外测试域名 |
| ChatGPT | 从 `chatgpt.com/cdn-cgi/trace` 读取 `loc`，表示该域名边缘地区 |
| Gemini | 从 Gemini 页面内部 `vXmutd` 字段读取地区，属于参考信号 |

CN 指中国大陆；其他地区显示原始地区码。绿色「非 CN」不代表账号地区正常或模型调用一定成功。验证码、403/429、超时、重定向、缺失地区字段都会保持未知或待确认。Gemini 字段不是稳定公开 API，网站更新后可能需要调整解析。

## 上网棒与维护

ADB 采集只读取运营商、信号、连接时长和流量，不读取短信、SIM 身份或管理密码。「刷新上网棒状态」会请求一次新采样；「重新连接上网棒」会中断上网与 VPN，需要勾选提示后执行。

套餐余量请查看运营商。管理入口只应向可信的车内网络开放，不要把 OpenWrt 管理端或 ADB 端口直接暴露到公网。

## 常见问题

| 现象 | 先检查 |
| --- | --- |
| Wi-Fi 搜不到或获取不到 IP | 供电、启动状态、频段兼容性；更改后等待回退或通过有线 LAN 管理 |
| VPN 已连接但国外打不开 | 六项检查、DNS、公司端出口策略；不能只看隧道状态 |
| 信号有数值但延迟空白 | VPN 可能断开，或检测主机不响应 ICMP；信号与 VPN 独立采集 |
| Gemini 显示未知 | 看 HTTP / 超时状态；页面字段变化也会导致未知，并不等于被识别为 CN |
| 历史不满 30 天 | 只显示真实采集过的时段，未积累的数据不会生成 |
| 有线没有优先 | 检查 DHCP、互联网探测、网段冲突；仅插入网线不代表有线互联网可用 |

## 飞书推送

首页右上角「飞书推送」进入专用设置页，设置总开关、各事件开关、三个独立地址及告警阈值。保存后再发送测试，下方可查看飞书接收结果。Webhook 留空保留已有地址，不回显完整链接。完整默认规则和断电/断网边界见 [飞书推送说明](NOTIFICATIONS.md)。


## HDMI 本地状态屏

可选的 `kk-car-hdmi` 服务直接输出到树莓派 HDMI；安装前备份启动配置，停止服务可恢复文本控制台。显示模式、安装、检查与撤销步骤见 [HDMI 状态屏](HDMI.md)。原设备启动配置与画面截图只保留在私密备份中。

## 本地 Wi-Fi 故障时的备用入口

已启用 VPN 备用管理时，可从公司网络使用树莓派当前 VPN 地址打开 `/cgi-bin/luci/admin/kkcar`，仍用原有管理员账户登录。VPN 重连可能改变地址；VPN 或 4G 本身断开时无法使用此入口。[排查与恢复说明](NETWORK-RECOVERY.md)


## DJI 一代模块

适配后用同一管理页面操作，无需 Mac 常驻。有线 WAN 健康时优先，DJI 蜂窝作为备用；关闭有线接口或有线探测失败后由现有出口维护服务选择蜂窝，并重建原本运行中的 VPN。

蜂窝详情增加 RSRQ 和 SINR，与 RSRP 一并显示；不支持的信号格数和时长显示空白，连接查询失败显示未知。DJI 没有沿用 F30A 的网页入口，避免打开错误设备。更换模块时历史仍保留，但切换当轮速率留空。

首页之外有独立的 [DJI 模块控制页](DJI-CONTROL.md)：查看四项信号及参考阈值、频段、固件、基带温度、SIM 锁状态、脱敏邻区信号、短信仓与 QMI 连接；需要时手动刷新或重连。页面打开后自动读取短信目录，此后每 30 秒更新；未读优先，点击会话在右侧读取正文，长短信按片段顺序合并，缺段明确显示。列表可按号码、时间或状态筛选；“回复这条”只预填号码，不自动发送。发送和删除都要管理员主动确认。目录或详情读取可能把未读短信标为已读；当前新短信使用 SIM `SM`，容量 40 条，树莓派 SD 卡扩容不改变 SIM 短信容量。新短信可单独开启飞书转发，树莓派运行时把完整短信加密归档到 SD 卡，解密私钥需留在设备之外。清理 SIM 原件前要先确认备份可解密。

同页“套餐与流量”显示今日、本月设备网卡收发和最近一次运营商报告。选择运营商、查询短信号码与指令，保存后可立即查询或每天定时校正。当前电信卡已实测 `10001` / `108` 的完整回复；移动/联通因地区及套餐格式差异需按实际回复确认能否自动解析。查询失败或回复不明确时，保留上次校正值。套餐剩余是运营商回复加本机后续流量的估算，不能替代运营商账单。「网页电话」现有试验性的拨号、接听、挂断与浏览器音频，来电可触发飞书文字提醒；但实机通话约 12 秒中断、双方无声，不能用于可靠通信，详见 [电话验证与限制](VOICE-CALLS.md)。GNSS 可手动启动、查询和停止；短时实机测试尚无卫星定位，只有实际 fix 才显示经纬度和速度。
