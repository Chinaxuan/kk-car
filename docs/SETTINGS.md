# 设置中心与本地屏幕菜单

连接 KK-Car 后，在任一页面选择「设置中心」，或访问 `/cgi-bin/luci/admin/kkcar_settings`。仍使用 OpenWrt 管理员登录。页面按显示、定时检查、后台服务与模块设置组织；网络、DJI、UPS 和通知的详细控制由下方目录进入原有页面。

## 电子纸设置

在实体屏幕按 KEY4 进入设置，**第一项是 Direction（显示方向）**。KEY2/KEY3 上下选择，KEY4 切换支持的值并保存，KEY1 返回首页。保存后显示结果；再次按 KEY4 可回到设置菜单。方向只支持 0°/180°，四键编号和职责不互换。菜单上方显示选中项序号与总项数。

| 设置 | 支持值 | 生效方式 |
| --- | --- | --- |
| 显示方向 | 0° / 180° | 当前写屏结束后全屏刷新，作废原方向局刷缓存 |
| 数据刷新周期 | 1 / 3 / 5 / 10 分钟 | 实体菜单或后台保存后生效；不改变后台采集周期 |
| 屏幕灰阶 | 开 / 关 | 开启时状态页的黑字边缘有深灰过渡；关闭后状态页使用黑白全刷 |
| 按键快速刷新 | 开 / 关 | 开启时翻页为黑白快刷，网格仍为连续黑线；关闭后灰阶开启时按键使用灰阶全刷，等待更长 |
| 菜单局部刷新 | 开 / 关 | 快速刷新开启时，小范围选择变化使用局刷 |
| 全刷前连续快刷次数 | 1 / 2 / 3 / 4 / 5 次 | 翻页快刷和菜单局刷共用计数；达到次数后下一次全刷，降低残影累积 |
| 控制器休眠延迟 | 18 / 30 / 60 秒 | 按键更新后闲置休眠；灰阶全刷完成后即休眠 |
| 开机首页 | 六个状态页 | 下次电子纸服务启动时生效；KEY1 始终返回行车总览 |
| 自动翻页 | 关闭 / 1 / 3 / 5 分钟 | 按键操作后重新计时；设置菜单中暂停 |
| 立即清理残影 | 执行全刷 | 不改刷新周期，等待当前帧完成 |

屏幕和后台共用 `/etc/kk-car/private/device-settings.json`，权限 0600，原子保存并按版本检查并发修改。后台只提交改过的字段；如果保存期间屏幕或另一页面改了设置，会拒绝旧版本，请重新读取后再保存。首次迁移读取旧 `epaper-settings.json` 的刷新周期，保留原来一分钟的设备设置；新配置优先。没有历史配置时，默认 180°、三分钟、灰阶与快刷/局刷开启、五次快刷后全刷、30 秒休眠、总览首页、自动翻页关闭。当前设备已保存为五次和 30 秒；设置中心会显示最近写屏模式及自上次全刷以来的快刷计数。

快刷次数只在连续翻页或菜单操作中累积；定时更新、屏幕休眠后的首次写屏和主动清残影仍会全刷。根据[微雪 V2 规格书](https://files.waveshare.com/upload/b/ba/2.7inch_e-Paper_V2_Specification.pdf)连续五次快刷/局刷后全刷的建议，后台上限为五次，不提供无限快刷。30 秒休眠使连续查看页面时更容易保持快刷，同时避免屏幕控制器长期不休眠；更长的休眠延迟可能增加用电。

后台「屏幕已应用」来自显示服务写帧成功后的版本读回，不只依据保存成功。电子纸刷新不是即时动画，写屏期间的短按可能丢失；断电时仍会保留最后画面，不能把画面存在当作设备仍开机。

设置中心同时显示电子纸**最近一次成功写入的画面**，可手动更新，页面打开后每 10 秒自动读取一次。镜像来自显示服务在 RAM 中保存的 264×176 PNG 帧，按屏幕当前页面和旋转设置生成；它不是摄像头拍摄的物理屏幕，无法呈现残影、断电后实际留存的画面或硬件故障。页面会标出写入时间、页数和设置界面状态；刷新页面也不会触发电子纸刷新。镜像仅通过现有 LuCI 管理员权限读取，RAM 文件 `/tmp/kk-car-epaper-frame.json` 为 0600，重启后需等首次写屏才有画面，不加入公开备份。

## HDMI 与网络检查

- HDMI 状态看板刷新周期支持 5 / 10 / 15 / 30 / 60 秒。默认 5 秒，下一帧采用新周期。此设置不修改 HDMI 分辨率、启动配置或网络。
- 自动网络检查支持 5 / 10 / 15 / 30 / 60 分钟，默认 10 分钟。运行中的调度器最多约 15 秒后读取新值，仍复用手动检查任务锁，保持忙时重试和单调时间调度。
- 更改开机启动开关只影响下次启动；更改运行状态只影响当前服务。两者互相独立。

## 后台服务控制

十个已安装服务可单独启动、暂停、重启、开启/关闭开机启动：电子纸、HDMI、自动检查、每分钟故障记录、4G 状态采集、VPN 延迟采集、飞书事件推送、短信归档/转发、来电监测、网页语音网关。页面先确认操作影响，再提交；设备只接受固定服务与动作，状态变化会拒绝过期操作。异步任务完成与实际运行状态分别显示，提交成功不等于运行成功。

暂停短信服务会停止自动归档及转发，模块短信仓可能积满；暂停语音服务会影响来电处理或当前网页声音。暂停日志或探测不会清空现有历史，但图表可能出现空缺。暂停电子纸后实体按键失效，可从后台启动回来。网络、DHCP、路由维护、出口切换和 UPS 保护采集未纳入这种通用服务暂停按钮，避免误停管理和供电基础服务。

常用控制还提供 VPN 开机连接与 UPS 来电自启，后者从原 UPS API 写入并读回；当前设备保留用户选择的关闭状态。完整控制目录：

- [连接设置](USAGE.md)：VPN、Wi-Fi、LAN/WAN 与维护；热点和端口沿用 125 秒确认回退。
- [DJI 蜂窝与通信](DJI-CONTROL.md)：GPS、短信、网页电话、联系人与通话记录、运营商查询和每日流量校正。
- [UPS 电源](UPS.md)：采样、RTC、低电策略、电池基准/保护与电源操作；修改电池参数继续使用原有确认。
- [通知中心](NOTIFICATIONS.md)：总开关、各事件与地址开关、阈值、冷却及测试推送。

## 安装与恢复

增量复制新 `device_settings.py`、更新后的 `epaper.py`、`auto-check.sh`、`hdmi.uc`、`kksettings.uc`、菜单和 ACL，以及 `settings.js/settings.css` 和各页面新导航。Python helper 与 shell 脚本设为可执行；重载 rpcd、清理 LuCI 菜单缓存并刷新页面，只重启电子纸、HDMI 和检查调度器。无需重启 network、dnsmasq、Wi-Fi、VPN 或整机。

把新增程序、菜单/ACL、前端、字体及私有 `device-settings.json` 加入 `/etc/sysupgrade.conf`，与旧的配置保留条目一起保存。配置仅放在加密/私有设备备份，不发布真实文件。回退代码时同时恢复电子纸及 helper 依赖；恢复旧版后由旧 `epaper-settings.json` 控制刷新，新的方向配置不会被旧代码读取。通用 Linux/macOS 可运行配置持久化测试；电子纸测试需要 Pillow，实屏仍须单独检查。

## 网络守护服务

设置中心增加第十一个后台服务「网络守护」，可启停和配置开机启动。检测/恢复开关、探测目标、连续轮数、冷却与动作限额在独立网络守护页；关闭守护不会停止现有网络。见 [网络守护](NETWORK-HEALTH.md)。
