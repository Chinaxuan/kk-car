# 备份与恢复

## 两份备份分别解决什么

| 备份 | 内容 | 保存位置 |
| --- | --- | --- |
| GitHub 项目仓库 | 源码、服务、静态规则、产品设计与使用说明 | 本私有仓库 |
| 设备配置备份 | 实际网络配置、PSK、管理员凭据等设备私密数据 | 自己的离线安全存储，禁止提交 Git |

源码与配置缺一不可。OpenWrt 配置备份不是完整 SD 卡镜像，重刷后还要安装匹配的软件包。

本仓库不包含管理员或热点密码、VPN PSK、SSH 私钥、WireGuard 密钥、实际 UCI 配置、抓包或历史记录。`.gitignore` 是辅助防误提交措施，不能代替发布前检查。请勿将父目录的 `work/`、`private/`、`outputs/` 整体拖入 GitHub。

## 设备损坏或换卡

1. 准备适合树莓派 3B+ 的 OpenWrt 镜像并刷卡，先验证稳定供电与本地管理。
2. 安装匹配固件的软件包，参考 `packages-reference.txt`。
3. 使用离线配置备份恢复网络和 VPN 凭据；若没有配置备份，需要重新填写双方认证资料。
4. 按 [部署说明](DEPLOYMENT.md) 恢复自定义脚本、面板、服务与启动项。
5. 按 LAN → 4G → Wi-Fi → VPN → 分流 → DNS → 面板顺序验证。
6. 确认 IPv6、VPN 断线保护、热点/网口回退和历史写入后，再用于行车。

## 更新失败时回退

保留最近一次确认可用的离线配置包以及对应源码版本。只有页面问题时优先恢复 CSS/JS；后台问题恢复对应脚本与服务。不要先删除路由服务：保留的不可达路由可能使网络无法恢复。

完整撤销有线 WAN 功能时，先恢复 LAN，再按架构清理 table 301 的规则和优先路由；不熟悉路由时使用维护前完整备份恢复。

## 后续 Git 备份

此仓库记录一次明确的基线版本。后续调整建议将源码和说明一并更新，提交前检查差异和暂存区；禁止加入密钥、整机配置压缩包和运行时历史。

历史数据约每 5 分钟保存，突然断电可能损失最近约 6 分钟。若需要历史本身的备份，应单独离线保存 `/etc/kk-car/history/`。

## 飞书推送的私密资料

`/etc/kk-car/private/notify.json` 含实际机器人 Webhook，不上传到仓库，也不应粘贴到 Issue。需要迁移时离线妥善备份，并恢复 0700 目录 / 0600 文件权限。丢失该配置后可以在页面重新填写地址。运行队列在 RAM 中，重启后不会恢复；启动标记没有重建网络所需的认证资料。


## HDMI 本地状态屏

可选的 `kk-car-hdmi` 服务直接输出到树莓派 HDMI；安装前备份启动配置，停止服务可恢复文本控制台。显示模式、安装、检查与撤销步骤见 [HDMI 状态屏](HDMI.md)。原设备启动配置与画面截图只保留在私密备份中。
