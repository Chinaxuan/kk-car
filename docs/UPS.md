# 52Pi EP-0136 UPS Plus 适配

本页用于树莓派 3B+、OpenWrt 25.12.5 和 52Pi UPS Plus EP-0136。打开 `http://192.168.88.1/cgi-bin/luci/admin/kkcar_ups`，使用原 OpenWrt 管理员登录。页面每 10 秒读取硬件；不依赖电脑常开。

## 已接入的状态

UPS 主控位于 I²C `0x17`，树莓派供电与电池传感器位于 `0x40`、`0x45`，RTC 位于 `0x68`。页面显示 USB-C/Micro-USB 充电输入、UPS 给树莓派的输出、电池端电压、电池温度、电量估计、控制器运行时间/充电时间、采样周期、来电自启状态以及树莓派欠压/降频标志。失去 I²C、设备不响应或读数越界时，会显示故障，而不保留旧值冒充实时数据。

硬件保护温度阈值为 65°C；页面从 50°C 起提示检查散热。电量百分比是 UPS 的估计值，厂家要求至少一次完整充放电才能校准。当前电流传感器虽可探测到，但校准寄存器未设置，页面暂不显示电流/功率。RTC 只确认存在，没有接管系统时钟或设置闹钟。检测到 UPS 并不等于已经验证断电续航、低电自动关机或恢复外部电源后自启。

## 安装到 OpenWrt

1. 按厂家方向安装 UPS、支柱及电池。电源只接 UPS 的输入端，**不要同时给树莓派自身供电口输入电源**。
2. 备份 `/boot/config.txt`，加入 `dtparam=i2c_arm=on`，安装与当前 OpenWrt 固件匹配的 `i2c-tools`，重启树莓派。
3. 确认 `/dev/i2c-1` 存在；`i2cdetect -y 1` 应发现上述四个地址。地址缺失时先检查硬件接触、供电和 I²C 配置。
4. 放置 `ups-read.uc`、`kkups.uc`、`ups.js`、`ups.css`，并更新 LuCI 菜单和 ACL。只刷新 rpcd 与 LuCI 菜单缓存，不需要重启 network、无线、DHCP 或 VPN。
5. 在管理页核对输入电压、输出电压和树莓派欠压标志，再确认原热点、WAN、VPN 仍在线。升级备份清单应包含以上页面/后台文件及 `/boot/config.txt`；软件包需另外记录。

相关源码路径见 `kk-car-ui/root/`。本设备已实测四个 I²C 地址和主控寄存器；固件版本寄存器为 10。第一次部署时启用 I²C 需要重启；页面更新本身不需要。

## 控制与恢复边界

当前页面是**只读监控**：不改写设备寄存器、不改变默认电池保护电压，也不发送 UPS 关机/重启命令。自动低电关机暂未启用。厂商的 Raspberry Pi OS 一键脚本还包含自动关机与遥测，不适合未经审核直接运行在本项目 OpenWrt 上。

页面读数异常时，可先在 SSH 中只读检查 `i2cdetect -y 1`、`ubus call kkups status` 和 `vcgencmd get_throttled`。要撤销适配，移除 UPS 页面/后台和菜单/ACL 条目；若不再使用 I²C，恢复原 `/boot/config.txt` 后重启。断电时不要拔 SD 卡；先从系统正常关机，再切断 UPS 输出。

硬件寄存器、校准和供电注意事项以 [52Pi EP-0136 官方说明](https://wiki.52pi.com/index.php?title=EP-0136) 为准。
